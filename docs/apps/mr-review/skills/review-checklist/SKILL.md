# Ревью MR

1. Дифф целиком: `git diff <база>...HEAD` или `glab mr diff <номер>`.
2. Корректность: граничные значения, ошибки, гонки, пустые и отсутствующие данные.
3. Контракты: поменялась ручка, формат или схема — кто их читает и не сломается ли он.
4. Тесты: новое поведение покрыто, тест проверяет поведение, а не реализацию.
5. Итог одним списком по важности: блокирует мерж, стоит поправить, мелочь.
